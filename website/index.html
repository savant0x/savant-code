03 — EXECUTION SCOPE

FOUR MODES

Set the ceremony level per session. Switch at runtime with /mode — from free-running hybrid work to a full audit trail on every single change.

DEFAULT

HYBRID

// SAVANT

Fast, low-friction writing. The harness watches every write — the full loop auto-engages when changes grow.

SCAFFOLD

// SAVANT-SCAFFOLD

Umbrella-FID project initialization. Scaffolds once, then hands back to Hybrid.

STRICT

// SAVANT-STRICT

The full ceremony on every change: FID per change, Forge writes, Verifier audits, Law-4 greps, archived with a changelog entry.

ANALYZE

// SAVANT-ANALYZE

Read-only. Search, inspect, and reason across the codebase — zero writes.

▸ RULE OF THUMB — if a change would hurt to get wrong (auth, payments, migrations, anything shipping to users), run STRICT. Exploring or iterating? HYBRID still has the harness watching Laws 1–3.
