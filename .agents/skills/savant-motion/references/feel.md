# Feel: curve, peak, close

Emotion is a design input with a mechanical footprint. Curve first, acts
second — a device chosen before the feeling is a device looking for a reason.

## 1. The feeling curve

One line per act, written **before** the acts exist:

```text
act 1  recognition  — the world already in motion, small headline
act 2  tension      — pinned stage, copy assembles line by line
act 3  relief       — luminance lifts, spacing opens, one quiet image
act 4  peak         — the one moment, largest span, the asset budget
act 5  resolve      — the ask, set as a sentence, holds without fading
```

Two adjacent acts with the same feeling means one is filler. Cut it here,
before assets exist.

## 2. The engineered peak

Peak-end rule, applied literally. The peak gets:

- the asset budget (the only long scrub, the only sequence),
- authored silence directly before it (an act with no motion devices),
- the most scroll room, by a visible margin.

A page with three peaks has none. Name the peak in BRIEF.md as the sentence a
visitor would say to a friend.

## 3. The mechanical link

Every emotion maps to a measurable visual delta so the Verifier can audit it:

| Feeling  | Mechanical signature                              |
| -------- | ------------------------------------------------- |
| Tension  | tighter spacing tokens, darker ground, kinetic type |
| Relief   | luminance lift, wider spacing, stillness           |
| Awe      | scale jump, the peak span, one signature move      |
| Momentum | pan track, velocity-published `--sm-vy`            |

A feeling-curve shift must produce a visible delta in spacing rhythm,
luminance, or layout complexity against the adjacent act — otherwise it is
prose, not design.

## 4. The close

The last feeling is the one they carry. The close resolves and holds: the CTA
arrives inside a resolving composition, never a fade to empty, never a bare
footer. Reduced-motion readers must get the same resolution statically.

## 5. The feel check (after building)

Scroll the finished page cold. One word per act for what you felt. Only then
open BRIEF.md and diff the felt curve against the intended curve. Where they
disagree the page is wrong, not the brief.
