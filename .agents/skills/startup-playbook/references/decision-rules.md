## Claims requiring caution

- **Incident:** At 24:33–26:16, the video contains only Altman's characterization of a so-called "Hugging Face" incident. It provides no independent report, logs, or technical detail.
- **Productivity figures:** Exact time-compression figures conflict rhetorically across the video. Preserve only the qualitative principle that a material capability gain should raise the goal ceiling.
- **Location:** The source itself qualifies the Bay Area advice as potentially time-sensitive. Check current network facts before applying it.
- **Forecast:** The 30:52–31:14 claim about model progress over the following six months is a time-sensitive subjective forecast, not a validated benchmark.
- **Thresholds:** The video does not define operational thresholds for "enough confirming data," a "safety floor," or "excessive concentration of power."
- **Captions:** The source uses English automatic captions that contain rolling overlap and possible errors in names or terminology.

## Evidence boundary

This Skill does not use visuals to prove business, historical, incident, or governance claims. Every core claim cites a speech window. If a user asks about visible state, explain that the package has no corresponding visual provenance; do not substitute decorative imagery as evidence.
