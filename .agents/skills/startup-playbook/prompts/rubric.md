# Founder Thesis Stress Test: Rubric and Example Structure

> This is a generator-created rubric. Load it only after the learner submits an attempt or explicitly asks to see the answer.

## Rubric (0–2 points each)

1. **Shift and ceiling:** 0 = only "AI is hot"; 1 = identifies one change; 2 = connects the change, relative advantage, and expanded problem ceiling.
2. **Business fundamentals:** 0 = missing; 1 = lists them; 2 = explains how each can be validated and why tool fluency does not replace it.
3. **Evidence-grounded conviction:** 0 = treats opposition as proof; 1 = includes supporting evidence; 2 = defines evidence that would both strengthen and weaken the belief.
4. **Relationship strategy:** 0 = purely transactional; 1 = identifies the target people; 2 = combines a small group of shared believers, networks, and genuine help into a long-term strategy.
5. **Data-generating step:** 0 = no action; 1 = action with an unclear outcome; 2 = makes the action, expected signal, and information gained from failure observable.
6. **Safety, power, and agency:** 0 = ignored; 1 = covers only one side; 2 = covers minimum safety, concentration risk, and human agency while labeling self-defined thresholds.
7. **Evidence honesty:** 0 = treats forecasts or incident characterizations as fact; 1 = applies some qualifications; 2 = systematically separates source claims, project facts, and inference.

## Minimal hint sequence

- First hint: identify only the lowest-scoring dimension and ask, "What observable fact would change your judgment?"
- Second hint: ask the learner to replace one abstract term with an observable state.
- After the retry: compare the attempt against the full rubric.
