# Savant Community Discord — Server Design

## Server Name

**Savant** (or "Savant Community")

## Channel Format

`emoji | name` — e.g., `📢 | announcements`, `🛠️ | general`

---

## Channel Structure

### 📢 INFORMATION

| Channel | Purpose |
|---------|---------|
| `📢 \| announcements` | Product launches, major updates, milestones |
| `📜 \| rules` | Server rules, code of conduct |
| `🎭 \| roles` | Self-assign roles via reaction |
| `❓ \| faq` | Common questions, troubleshooting |

### 🛠️ SAVANT CODE

| Channel | Purpose |
|---------|---------|
| `⌨️ \| general` | General Savant Code discussion |
| `🔧 \| support` | Bug reports, help requests |
| `💡 \| feature-requests` | Suggest new features |
| `🏆 \| showcase` | Share what you've built |
| `📝 \| release-notes` | Patch notes, version updates |
| `⚡ \| tips-tricks` | Power user tips, workflow optimization |

### 🔬 SAVANT INFERENCE (Phase 2)

| Channel | Purpose |
|---------|---------|
| `🧠 \| inference-general` | Provider discussion, model routing |
| `🚨 \| inference-support` | API issues, integration help |
| `📡 \| inference-announcements` | Provider updates, pricing changes |

### 🦀 SAVANT CORE (Phase 3)

| Channel | Purpose |
|---------|---------|
| `⚙️ \| core-general` | Rust framework discussion |
| `🏗️ \| core-development` | Architecture, crate design, contributions |
| `🚀 \| core-announcements` | Core releases, roadmap updates |

### 🔨 DEVELOPMENT

| Channel | Purpose |
|---------|---------|
| `📊 \| dev-updates` | Internal dev progress (public-facing) |
| `🧬 \| architecture` | Technical deep dives, design decisions |
| `🤝 \| contributing` | How to contribute, PR guidelines |
| `🏛️ \| echos` | ECHO Protocol discussion, governance philosophy |

### 💬 COMMUNITY

| Channel | Purpose |
|---------|---------|
| `☕ \| off-topic` | General chat, non-Savant discussion |
| `👋 \| introductions` | New member intros |
| `😂 \| memes` | Dev humor, AI memes |
| `🏆 \| showcase` | Projects built with Savant tools |

### 🔒 INTERNAL (Staff Only)

| Channel | Purpose |
|---------|---------|
| `🔒 \| staff-chat` | Internal team discussion |
| `🚀 \| launch-prep` | Launch coordination |
| `🚨 \| incidents` | Outage/incident response |
| `🤖 \| bot-commands` | Bot configuration, moderation |

---

## Branding Guidelines

- **Color scheme:** Dark background, neon blue/purple accents
- **Tone:** Technical but approachable, no corporate speak
- **Emoji:** Custom emoji set (Savant logo, ECHO icon, agent emojis)
- **Welcome message:** Warm, concise, points to rules and roles

## Scaling Plan

1. **Phase 1 (Launch):** Savant Code channels only, minimal staff
2. **Phase 2 (Post-launch):** Add Inference channels as product ships
3. **Phase 3 (Ecosystem):** Add Core channels, contributor program
4. **Phase 4 (Scale):** Add regional channels, language support, partner program
