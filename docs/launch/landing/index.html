Code that actually works.

Savant Code is a terminal-native AI coding assistant that runs a 9-agent auditing loop before any change touches your repo. Local-first with Ollama. BYOK when you choose a remote provider.

View on GitHub Read ECHO Protocol

A terminal demo asset is not yet available. Install the current package or inspect the open-source CLI and ECHO Protocol from the links above.

9-Agent Perfection Loop

Detective, Thinker, Forge, Verifier, and five more agents coordinate under the ECHO Protocol. The writer never audits its own work.

Local-first with Ollama

Auto-detects a running Ollama daemon and routes inference locally. No API key. No account. Your code stays on your machine.

Permission Mode Sandbox

Run in safe, prompt, or unsafe mode. Destructive commands and network access are gated by your chosen permission level.

Install in one command 
npm install -g savant-code

Built with TypeScript, Bun, and React for the terminal UI. A public Discord community is not yet available; please open an issue on GitHub.
