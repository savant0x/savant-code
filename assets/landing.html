THE PERFECTION LOOP

No code is written until a FID — a Feature Implementation Document — converges through the loop. Hard 10-iteration cap. 10% Levenshtein change-cap per pass. The loop runs on the document, not the code.

HARD GATES BEFORE THE WRITE

Enforcement lives at the tool executor — structural, mechanical, and fail-closed. Watch a session run the loop:

  • EHEL15 laws at the tool boundary

    Pre-write gates block read-before-touch, verify-before-proceed and search-before-create before they happen. Hybrid warns. Strict blocks all fifteen.

  • ZTAPZero-trust provenance

    Per-role Ed25519-signed write receipts on an append-only session ledger. /attest exports verifiable trust offline.

  • GRAPHCode Universe export

    tree-sitter index → blast-radius queries, Louvain domain clusters, and a fully offline interactive HTML map of your repo.

  • SKILLSSelf-improving, operator-gated

    Every tool failure is captured mechanically, deduped, and drafted into quarantined skills you must explicitly trust.

  • LOCALLocal-first inference

    Ollama auto-detected with zero keys — or route through OpenRouter's free tier and seven other hosted gateways.

  • REWINDCheckpoints without git

    Per-turn snapshots of every touched file restore code, conversation, or fork a new session — /rewind.
