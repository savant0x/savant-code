## Highlights

v0.0.9 is the first launch-readiness release. It hardens privacy and safety defaults, removes first-run friction,
finalizes launch artifacts, and fixes a long-standing session-history reliability issue.

### Trust & Verification (FID-2026-0728-003)

Privacy-first is now backed by code, not just copy.

- **Telemetry and ads are strictly opt-in.** `adsEnabled` now defaults to `false`.
- **Secrets are redacted in logs.** `sanitizeSecrets` scrubs tokens, keys, and passwords from analytics, Axiom, and
  disk log paths.
- **Config directory unified.** CLI and SDK now share `~/.savant-code[-env]/` (legacy `~/.config/manicode[-env]/` path
  removed).
- **`docs/privacy.md`** documents data boundaries, credential storage, network calls, retention, and user controls.

### 🛡️ Safety Track — Sandbox Engine Phase 2 (FID-2026-0728-004)

The sandbox engine now enforces permission modes at runtime.

- **Network gating by mode:**
  - `safe` — blocks all network tools
  - `prompt` — returns a prompt (downgraded to deny in headless mode)
  - `unsafe` — allows network tools
- **Destructive shell command denylist** is enforced in `safe` mode.
- **`/permissions`** slash command (aliases `/sandbox`, `/safety`) is wired and persists across sessions.
- **`--permission-mode safe|prompt|unsafe`** CLI flag is parsed at startup.

### ⚡ Friction Reduction (FID-2026-0728-005)

First-run setup is now nearly invisible when Ollama is present.

- **Automatic Ollama detection** on first launch.
- **Local-first default** — if Ollama is running, inference is routed locally with no API key or account.
- **`/health` slash command** (aliases `/status`, `/check`) reports provider status, available models, and permission
  mode.
- **Persisted direct-provider settings** so returning users keep their local setup.

### Launch Artifacts (FID-2026-0728-006)

All public-facing launch materials are now in the repo.

- `docs/launch/hn-post.md` and `hn-first-comment.md`
- `docs/launch/twitter-thread.md` and `mastodon-thread.md`
- `docs/launch/newsletter-pitch.md`
- `docs/launch/incident-response.md` — rollback procedures for npm, GitHub releases, landing page, and social
  amplification
- `docs/launch/landing/index.html` — minimal dark-mode landing page
- README hero section rewritten with one-sentence pitch, install command, and Ollama quick-start

### 📜 Full Session Capture in `/history` (FID-2026-0728-008)

Fixed the `/history` command silently dropping mid-stream messages.

- **Filesystem is now the source of truth** for chat state; the database is a fallback only when filesystem state is
  missing or unreadable.
- **`completed` marker** added to `chat-meta.json`: mid-stream checkpoints mark `completed: false`, turn-end saves mark
  `completed: true`.
- **Incomplete sessions show a warning indicator** in `/history` so users can identify interrupted sessions.
