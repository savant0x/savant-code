### ⚡ Orchestrator Optimization (FID-001, FID-002, FID-056)

Three structural changes that reduce LLM calls from 6-8 to 3-4 per task:

- **Hybrid Mode** — Savant writes code directly via `write_file`/`str_replace`; Forge reserved for complex tasks
  (50-60% fewer LLM calls)
- **Parallel Agent Batching** — Detective + Researcher + Thinker fire in parallel via `Promise.allSettled`
- **Smart Phase Transitions** — Skip RED/GREEN/AUDIT when criteria met; Law 3 never skipped
- **Batch Operations** — Write all files first, verify once at the end
- **Verifier Trigger** — Objective criteria replace subjective "skip if straightforward" (10+ lines, 2+ files, new API,
  security)
- **Local Token Estimation** — Eliminates serial HTTP round-trip for external runs
- **Conditional Context-Pruner** — Skips spawn when context < 80% of limit

### 🌐 Provider & Model System (FID-034, FID-054, FID-062)

- **OpenCode Go** — Dual-protocol provider (OpenAI + Anthropic compatible), 15 curated models via subscription
- **Context Window** — Resolved from OpenRouter catalog (no more hardcoded 200k)
- **Model Metadata** — Injected into system prompts via `PLACEHOLDER.MODEL_INFO` for accurate self-reporting
- **Default Model** — Changed from hardcoded expensive models (`anthropic/claude-opus-4.8`, `openai/gpt-5.4`) to
  `openrouter/free`

### 🔧 Direct-Provider Mode (FID-061)

- `isDirectProviderMode()` — Single source of truth for direct-provider detection
- Request-level 503 guard prevents stub token from reaching real backend
- `Infinity` usage stub replaced with `Number.MAX_SAFE_INTEGER`

### 🧹 Legacy Cleanup (FID-066, FID-067)

- **10 dead Codebuff template types removed** — `base`, `base_free`, `base_lite`, `base_max`, `base_experimental`,
  `claude4_gemini_thinking`, `superagent`, `base_agent_builder`, `agent_builder`, `example_programmatic`
- **`file_picker` → `scout`, `reviewer` → `verifier`** — Renamed across 20+ files (107+ replacements)
- **`ORCHESTRATOR_IDS` set** — Replaces fragile `startsWith('base')` special case

### 🛠️ Tooling & DX (FID-004, FID-065, FID-064)

- **`run_readonly_command`** — Read-only terminal commands from any ECHO phase, bypassing FSM gates
- **`&&` chaining** — Allowed for safe read-only command chains (e.g., `cd sdk && bun run typecheck`)

- **Automated test runner** — `scripts/run-az-test.sh` with 148 tests across 28 phases
- **Slash command cleanup** — Removed 7 dead entries, 2 orphaned handlers
