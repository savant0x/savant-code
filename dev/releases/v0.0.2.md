## What This Release Is

This is the **pre-rebrand safety checkpoint** — a clean, tested snapshot of the monorepo at the `@savant-code/*`
workspace state, intended as a safe restore point before the full `@savant-code/*` -> `@savant-code/*` workspace-wide
rebrand begins on the next push.

**Why pre-rebrand instead of post-rebrand:**

- 1,131 consumer imports across the repo reference `@savant-code/X` workspace package names — collapsing the rebrand
  into a single push would create one massive diff
- This checkpoint gives us a known-good state at the original `@savant-code/*` names that the rebrand work can be
  measured against
- Workspace-level rebrand will land in the next push as its own atomic operation

**What's already pre-renamed:**

- CLI binary names: `savant-code`, `savant-free`
- Display names + ECHO identity + 9-agent roster
- README, AGENTS.md, CONTRIBUTING.md, ARCHITECTURE.md
- LICENSE file: `Apache-2.0` (was MIT, fixed in FID-022)

**What's still @savant-code/* (deferred to next push):**

- Workspace package names
- Environment variable names (CODEBUFF_API_KEY, SAVANT_FREE_MODE)
- npm-script names (dev:savant-free, build:savant-free)
