## Pre-Existing Windows Platform Test Issues

18 SDK tool test failures across 3 files are **pre-existing platform test infrastructure issues** (NOT regressions from FID-014):

**Root cause:** Mock fs uses literal keys from test setup (e.g., `{ files: { '/repo/src/file.ts': '...' } }`), but `resolveFilePath` returns platform-native paths (`C:\repo\src\file.ts` on Windows). Keys don't match → "File not found" → tests fail.

**Baseline verification (before FID-014):**
- change-file.test.ts: 0 pass / 7 fail
- apply-patch.test.ts: 1 pass / 11 fail
- path-utils.test.ts: 2 pass / 5 fail

**After FID-014 v3:**
- change-file.test.ts: 1 pass / 6 fail (test #7 inverted and now passes — +1)
- apply-patch.test.ts: 1 pass / 11 fail (unchanged)
- path-utils.test.ts: 6 pass / 1 fail (FID-014 improved 4 tests via cross-platform rewrite — +4)

**Production impact:** None. Linux runs are clean. Mock fs isn't used in production.

**Fix tracked as FID-2026-0718-015.**
