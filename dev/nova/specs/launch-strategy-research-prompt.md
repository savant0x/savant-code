# Gemini Deep Research Prompt — Launch Strategy for Savant Code

## Context

I'm launching an open-source, free-tier AI coding agent CLI called "Savant Code" (Apache-2.0 licensed). It's a
TypeScript monorepo with an ECHO Protocol governance system that enforces code quality through a 9-agent roster. Key
differentiator: the agent self-audits through a perfection loop before shipping code. It runs via BYOK (Bring Your Own
Key) or local Ollama models. The ad infrastructure is wired but not yet active.

I need comprehensive market research on the best launch strategy.

---

## Research Questions

### 1. Launch Channels & Distribution

- What are the most effective launch channels for open-source developer tools in 2025-2026?
- Product Hunt vs Hacker News (Show HN) vs Reddit (r/programming, r/LocalLLaMA, r/MachineLearning) — which drives the
  most sustained traction for CLI dev tools?
- What developer newsletters or blogs (e.g., Console, TLDR, ByteByteGo, Hacker Newsletter) accept submissions from
  open-source projects?
- How do successful coding agents (Cline, Aider, OpenHands, Continue, Cursor) distribute their tools? What channels did
  they use at launch?
- Is Twitter/X still effective for developer tool launches, or has it shifted to other platforms (Bluesky, Mastodon, dev.to)?
- What role do GitHub stars play in discovery? How do projects accelerate star growth?

### 2. Competitor Launch Strategies

- How did Codebuff launch? What channels did they use? What was their initial traction?
- How did Cline (formerly Claude Dev) grow from zero to its current user base?
- What did OpenHands (formerly OpenDevin) do to gain 50K+ GitHub stars?
- How did Goose (Block) leverage being a corporate-backed open-source project?
- What pricing models are coding agents using? (Freemium, usage-based, seat-based, BYOK)
- What's the typical conversion rate from free-tier users to paid users in developer tools?

### 3. Pricing & Monetization

- What's the standard ad CPM for CLI text ads in developer tools? Is $20-45 CPM realistic?
- How do developer tools structure their free tier vs paid tier? What's the typical feature split?
- What's the break-even point for a free-tier coding agent (users needed to cover inference costs)?
- Are there examples of developer tools successfully using ad-supported models? What ad networks work for CLI/terminal products?
- How do tools handle the "data for compute" model? Which providers accept developer workflow data as payment for inference?

### 4. Pre-Launch Preparation

- What should a launch-ready open-source project have before going public? (README, docs, landing page, contributing
  guide, license, etc.)
- How important is a landing page vs just a GitHub repo? What should the landing page include?
- What documentation structure works best for developer tools? (README + docs site, or just comprehensive README?)
- Should I create a Discord/Slack community before launch or after?
- What's the ideal time between "first public commit" and "official launch announcement"?

### 5. Launch Timing & Sequencing

- Is there a best day of week / time of year to launch a developer tool?
- Should I do a soft launch (quiet GitHub push) before the official launch?
- How do I sequence the launch across multiple channels? (e.g., Hacker News first, then Product Hunt, then Reddit?)
- What's the typical "launch week" playbook for an open-source dev tool?
- How do I maintain momentum after the initial launch spike? What's the 30/60/90 day strategy?

### 6. Community & Growth

- What's the most effective way to build an early adopter community for a coding agent?
- How do I get beta testers before launch? Where do developer early adopters hang out?
- What role do influencers/developers with large followings play in dev tool launches? How do I get their attention?
- Should I offer exclusive access or features to early adopters?
- How do successful open-source projects handle feature requests and community contributions without losing direction?

### 7. Risk & Differentiation

- What are the biggest risks when launching a coding agent in a crowded market (2025-2026)?
- How do I differentiate from Cursor, GitHub Copilot, Cline, and other established players?
- What messaging resonates with developers who are frustrated with existing coding agents?
- How do I position "quality over speed" as a competitive advantage?
- What should I avoid doing at launch? Common mistakes that kill developer tool launches?

---

## Output Format

For each question, provide:

1. **Direct answer** with specific data/examples where available
2. **Source** (article, case study, or data point)
3. **Actionable recommendation** for Savant Code specifically

Prioritize insights from 2024-2026. Focus on what actually worked, not theoretical best practices.
