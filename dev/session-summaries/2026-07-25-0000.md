## Lessons Learned

1. FSM phase gating must account for Hybrid Mode — simple tasks should not require FID-Bound Execution
2. Command allowlists should be reviewed against real-world usage patterns
3. Cross-platform shell escaping is a recurring issue — prefer `spawn` with `shell: false`
4. Agent prompts must explicitly instruct error checking on tool outputs
5. Sub-agent output format must be validated at the tool level
6. The `complete` phase needs explicit auto-transition instructions
7. Path resolution in `read_subtree` should use prefix matching with boundary checks
8. Tool parameter descriptions must match actual usage — agents misuse `flags` because `cwd` was not exposed
9. When a root cause is revised during GREEN phase, document the revision clearly
