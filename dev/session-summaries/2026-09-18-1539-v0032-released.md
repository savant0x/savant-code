## Notable Findings (recorded for the harness)

- **TTY confirm is structural in this environment**: `release:public` manual
  mode requires `stdin.isTTY` — the agent shell has no tmux/winpty path to a
  real console. The operator's own terminal is the designed confirmation
  point; agent-side execution attempts correctly fail closed.
- **Automation-mode vs preaudit design gap** (not hit today): with the
  worktree clean, `SAVANT_CODE_RELEASE_AUTOMATION=1` fails at
  "Automation mode found no changes to commit" because the pre-audit blocks
  dirty trees before the automation-commit stage. Pre-0.0.31 releases used
  automation mode before the preaudit existed (FID-2026-0913-004). Candidate
  FID: exempt the automation commit path from the clean-tree block, or allow
  the automation commit stage to accept a clean tree (skip + tag HEAD).
