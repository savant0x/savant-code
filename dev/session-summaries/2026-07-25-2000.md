5. **Scribe deadlock:** Scribe couldn't write files in idle phase. Resolved by user ending turn.

## Lessons Learned

1. FID status is a claim, not ground truth — always verify against codebase
2. Law 1 applies to status reporting, not just code edits
3. Word-boundary regex (`\bGOAL_SATISFIED\b`) is more robust than `includes()`
4. Static imports preferred over dynamic `import()` for synchronous operations
5. `useState` must be at top of file with other React imports
6. ContextCompactor reconstruction from usage patterns is possible but risky — always backup critical files
