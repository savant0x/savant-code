## Findings raised, not parked

- **The conflation was the bigger defect.** The 19 `edit-noop` records were partly *mismatch* records: two
  classes were arriving through one message. That is why the lane was never fixed by improving the
  mismatch text alone — the model was being told "nothing to do" about a failed edit.
- **The no-op stays on the error channel, with a cited reason.** A success shape would send the unchanged
  file through `postStreamProcessing`, which partitions on `'error' in result`, and would rewrite the file
  and open a client round trip for nothing. The separation belongs at the result-vocabulary level
  (`-021`'s machinery), not in a rename here.
- **The mutation fix is real; its production trigger is not claimed.** `grep -rn 'Object.freeze'` finds no
  frozen tool results in the runtime — the 2026-10-01 session's path is unproven, and there is no
  `handleStrReplace` test harness, so no regression test pins the fix.
- **A line-ceiling lesson.** My first test additions pushed an existing suite to 321 lines against the
  300 ceiling and the quality gate caught it; the cases moved into their own file. Test files are subject
  to the same ceiling as source, and appending to a near-cap suite is how a lane turns its own gate red.
