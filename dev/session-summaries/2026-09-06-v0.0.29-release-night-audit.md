## Lessons (this session)

- Re-read every edit before running tests: one dropped shell
  line-continuation backslash and one broken intermediate refactor were
  both caught by immediate re-reads, not by failures.
- `fid:verify` gate parsing consumes everything under the Verification
  Gates heading until the next `##` — trailing prose inside that section
  parses as malformed gate lines. Gate list must be the only content.
- `fetchUpdaterManifest` calls `fail()` on any non-ok status; absence
  assertions need their own raw probe (404 proves, ok contradicts,
  anything else is unverifiable).
