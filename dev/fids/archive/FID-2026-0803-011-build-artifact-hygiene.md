# FID: Build Artifact Hygiene (stale `cli/bin/` artifacts)

**Filename:** `FID-2026-0803-011-build-artifact-hygiene.md`
**ID:** FID-2026-0803-011
**Severity:** low
**Status:** analyzed
**Created:** 2026-08-03
**Author:** Savant

**Summary:**
The stale-artifact follow-up flagged in FID-2026-0803-010's amendment was
re-investigated with git-aware evidence, which **corrected the premise**: the
`cli/bin/` artifacts are **gitignored, not committed** — so there is no
repo-pollution problem and no "prevent future commits" work needed. The real
issues are (1) ~360 MB of stale local build artifacts embedding pre-session
source that consumers silently use, (2) no way to clean them in one command,
and (3) an inaccurate note in the FID-0803-010 amendment that must be
corrected for audit-trail honesty.

| BH-1 | `FID-2026-0803-010` amendment, "Follow-up note" | Says "committed .exe binaries" — false: `cli/bin/` is gitignored (root `.gitignore:42-43`, `cli/.gitignore` `bin`) and `git ls-files cli/bin/` is empty |
| BH-2 | `cli/bin/` (working tree) | ~360 MB stale artifacts (Jul 28-31): `savant-code.exe` 143 MB, `savant-free.exe` 143 MB, `index.js.map` 21 MB, `savant-code-win32-x64.tar.gz` 52 MB, `tree-sitter.wasm`, `env.json` — embed pre-session source (`createAgentConfig`, old `getSession(id)!`) |
| BH-3 | `cli/package.json` scripts + `cli/scripts/build-binary.ts` | No `clean` script; every build drops a 21 MB `index.js.map` sibling (bun quirk — emitted despite `--sourcemap=none`) that the release tarball doesn't ship and nothing references |

### Finding details

**BH-1 (docs correction)** — the amendment's follow-up note states "`cli/bin/
index.js.map` + the committed `.exe` binaries are stale build artifacts". The
repo-wide grep that found them did not respect `.gitignore`. Git-aware checks:
`git ls-files cli/bin/` → empty; root `.gitignore:42-43` comments "Compiled CLI
binaries and their sibling artifacts" with `/cli/bin/`; `cli/.gitignore` has
`bin`. The only tracked binary in the repo is the intentional vendored
`cli/../sdk/vendor/ripgrep/x64-win32/rg.exe`. The note must be rewritten to say
"local stale build artifacts (gitignored — nothing tracked)".

**BH-2 (stale local artifacts)** — the working tree carries ~360 MB of
Jul 28-31 build output. Consumers only existence-check: the e2e harness
(`savant-free/e2e/utils/binary-helpers.ts`) resolves `cli/bin/savant-free` and
`requireSavantFreeBinary()` throws only when missing; `scripts/tmux/tmux-start.
sh` defaults to `cli/bin/savant-code`; `cli/package.json` bin entry points at
`./bin/savant-code`. A stale binary therefore runs silently in e2e/tmux/dev.
All artifacts are regenerable: `bun run build:binary` (cli), `bun savant-free/
cli/build.ts <version>` (free variant), and root `bun run ci` → `build:savant-
free`. Deleting them is safe and self-healing.

**BH-3 (no clean path + unwanted build byproduct)** — `cli/package.json`
scripts (`dev`, `prebuild:agents`, `build:binary`, `release`, `test`,
`test:tmux-poc`, `typecheck`) have no `clean`. Verified during
implementation: every build drops a 21 MB `index.js.map` sibling in
`cli/bin/` even though `build-binary.ts` passes `--sourcemap=none` (bun
1.3.11 quirk — the file is emitted regardless, timestamped fresh). The
release tarball ships only `<binary>`, `tree-sitter.wasm`, and `env.json`
(`.github/workflows/build-release-binaries.yml`), nothing references the map,
and nothing ever cleaned it. Fix: (a) a `clean` command purging `cli/bin/`,
and (b) a post-compile removal of the unwanted map in `build-binary.ts`.

### Fix details and rejected alternatives

**BH-1** — one paragraph rewrite in the archived FID, preserving the rest of
the amendment. Rejected: leaving the inaccurate note (violates audit-trail
honesty — the same standard that drove the DB-B evidence correction).

**BH-2** — `rm -rf cli/bin` (safe: gitignored, nothing tracked, all files
regenerated by existing build commands). Rejected: "refresh" by rebuilding —
the binaries are per-version release artifacts; a stale local build serves no
purpose and the CI workflow builds its own. Rejected: `.gitignore` additions —
already covered by root `.gitignore:42-43` + `cli/.gitignore`.

**BH-3** — tiny typed script + package.json script; plus a 3-line post-compile
`rmSync` of `index.js.map` in `build-binary.ts` (unwanted dead weight —
`--sourcemap=none` is already requested, and neither the tarball nor any code
ships/references it). Rejected: `rm -rf bin` as a raw script value (not
portable to cmd on Windows); making `build:binary` clean the WHOLE output dir
first (would delete the sibling savant-free binary on alternating builds);
wiring clean into `ci` (CI builds from clean checkouts anyway).
