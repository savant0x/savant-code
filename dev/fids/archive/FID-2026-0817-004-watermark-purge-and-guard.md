# FID-2026-0817-004 — Unauthorized coding-agent contributor credit purge + permanent watermark guard (closed)

**Severity:** high (public-repo contributor integrity)
**Status:** closed
**Created:** 2026-08-17
**Closed + archived:** 2026-08-17

## Background

The operator found `@codebuff-team` (Codebuff) and `@CommandCodeBot`
("npm i -g cmd") listed as **contributors** on
`github.com/savant0x/savant-code` — two coding agents never approved for any
attribution. Git-author forensics showed the watermarks were not author
identities but **`Co-Authored-By:` trailers inside commit messages**: GitHub
converts co-author trailers into contributor credit, so an unapproved
coding-agent trailer silently credits its org on the repo page.

Forensics results:

- **21 commits** carried `🤖 Generated with Codebuff` +
  `Co-Authored-By: Codebuff <noreply@codebuff.com>` (all authored as
  `savant0x`, 2026-07-17 → 2026-08-17, including 10 committed on the
  incident day). Author/committer identity was always the operator's own —
  only the trailer credited Codebuff.
- **0 commits** carried CommandCodeBot trailers in the reachable history —
  `.githooks/commit-msg` (FID-2026-0812-009) had already blocked new
  CommandCodeBot trailers; the @CommandCodeBot contributor entry was stale
  GitHub cache from pre-rewrite history.
- The existing guard's blind spot: it blocked CommandCodeBot only — the
  Codebuff identity was never in the deny list, so every new Codebuff
  session kept appending its trailer.

## Remediation 1 — history purge (operator-approved Scope 1: full purge)

Stripped the trailer + watermark lines from commit messages across ALL refs
with `git filter-branch --msg-filter` (`sed` deleting `Generated with
Codebuff` lines and `Co-Authored-By: …codebuff` lines), `--tag-name-filter
cat` over `-- --all`:

- 14 commits rewritten (messages only) — trees byte-identical pre/post
  (`e26c1fe…` tree on main before and after).
- `main` force-pushed with an explicit lease pinned to the pre-rewrite
  remote head (`193fd51…`); the pre-push credential scan was restored to a
  verifiable state via the pre-rewrite backup bundle (the prior `git gc
  --prune=now` had removed the old objects the scan needs to materialize the
  pushed range).
- `v0.0.25` annotated tag re-created and force-pushed (commit target
  `1098e37…` → `8c34b19…`); every other tag's commit target verified
  unchanged (messages-only rewrite of the recent chain).
- Post-rewrite verification: 0 trailer lines in any reachable ref
  (`grep -ic` over `git log --all --format=%8`), contributor API lists only
  `savant0x`, release assets still 5/5, npm `savant-code@0.0.25` untouched.
- Backup bundle retained outside the repo
  (`%LOCALAPPDATA%\Temp\savant-code-pre-purge-backup.bundle`).

Note: GitHub contributor caches may lag the rewrite; the CommandCodeBot
legacy entry is expected to age out. Server-side enforcement (branch
protection rules / a CI commit-message check job) remains out of scope here —
the local gates are fail-closed and run on every push.

## Remediation 2 — permanent guard (`never again`)

1. **`.githooks/commit-msg`** now blocks BOTH known agent identities in
   the same grep: `Co-Authored-By:` lines matching `commandcodobot|
   commandcode[.]ai|codebuff`, and `(generated with|generated by)
   +codebuff` watermark lines. Legitimate unrelated co-authors still pass.
   Smoke-tested: bad-Codebuff → exit 1, bad-cmd → exit 1, legitimate → 0,
   plain → 0.
2. **`scripts/pre-push-scan.ts`** (the focused-range credential scan, F-A
   gate) now also scans every pushed commit **message** with the same deny
   patterns (`commitWatermarkLines` helper, exported + unit-tested): a
   trailered commit in the pushed range blocks the push fail-closed even if
   the commit-msg hook was bypassed with `--no-verify`.

## Verification

- `scripts/pre-push-scan.test.ts`: 17 pass / 0 fail (4 new watermark
  cases: pure-helper detection of both bots, legitimate co-author + prose
  mentions allowed, end-to-end blocked push, end-to-end clean push).
- Hook smoke: 4/4 expected exits.
- Rewrite asset check: trees byte-identical, tag targets (except v0.0.25,
  intentionally) unchanged, remote main + tag + release 5/5 verified.
- Pre-push gate on the rewritten history: credential scan + ESLint +
  markdownlint + typecheck + tests + prettier all exit 0.

## Resolution

Contributor accounts codebuff-team and CommandCodeBot are no longer in
the rewritten history. The guard now covers both identities at the two
enforcement points that can stop an agent watermark from reaching GitHub:
commit creation (commit-msg) and the pushed range (pre-push scan). Closed +
archived 2026-08-17.
