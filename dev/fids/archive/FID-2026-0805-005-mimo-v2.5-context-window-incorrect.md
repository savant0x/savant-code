## Summary

The `inferContextLength()` function in
`cli/src/utils/openrouter-models/static-catalogs.ts`
hardcodes MiMo V2.5's context window to 128,000 tokens, but MiMo V2.5
actually has a 1M (1,000,000 token) context window. This causes the
system prompt to display incorrect context window information to the
agent, potentially limiting context utilization.

## Environment

- **OS:** win32
- **Language/Runtime:** TypeScript / Bun
- **Tool Versions:** Savant-Code v0.0.21
- **Commit/State:** Uncommitted working tree on main

## Detailed Description

### Problem

In `cli/src/utils/openrouter-models/static-catalogs.ts`,
the `inferContextLength()` function (line ~140) contains:

```typescript
// MiMo V2.5: Xiaomi reasoning models, 128k context
if (lower.includes('mimo')) return 128_000
```

This returns 128,000 for any model whose name contains "mimo",
including MiMo V2.5 and MiMo V2.5 Pro.

### Expected Behavior

MiMo V2.5 has a 1M (1,000,000 token) context window. The function
should return `1_000_000` to match the actual model capability.

### Root Cause

The comment and value were set at 128k when the model was first added
to the catalog, likely before the full 1M context window specification
was confirmed. Other 1M-context models (Grok, GLM) in the same
function correctly return `1_000_000`.

### Evidence

```typescript
// cli/src/utils/openrouter-models/static-catalogs.ts
// line ~138-140
if (lower.includes('grok')) return 1_000_000  // ✅
if (lower.includes('gpt')) return 256_000      // ✅
if (lower.includes('qwen')) return 128_000     // ✅
if (lower.includes('glm')) return 1_000_000    // ✅
if (lower.includes('mimo')) return 128_000     // ❌
```

The value flows through:
`inferContextLength()` → `fetchOpenCodeGoModels()` →
model catalog → `formatModelInfo()` → system prompt → agent context.

## Proposed Solution

### Approach

Change the hardcoded context window for MiMo from 128,000 to
1,000,000 to match the actual model specification.

### Steps

1. In `cli/src/utils/openrouter-models/static-catalogs.ts`,
   change `return 128_000` to `return 1_000_000` on the MiMo line
2. Update the comment from "128k context" to "1M context"
3. Verify typecheck passes

- Typecheck passes for the `cli` workspace

## Lessons Learned

When adding new model entries to hardcoded catalogs, always
cross-reference the model's actual context window specification
rather than using a default or outdated value. Consider adding
a comment with the source URL for the context window spec.
