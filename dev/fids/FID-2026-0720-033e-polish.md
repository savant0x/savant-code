## Summary

Polish the TUI with animations, syntax highlighting, and markdown upgrades. This is the final cosmetic phase that adds visual flair to the functional foundation built in phases A-D.

**OpenTUI Integration:** This phase leverages OpenTUI's animation and post-processing systems:
- **Timeline** and **useTimeline** hook for smooth animations
- **Post-processing effects** for visual polish (verified API from `resources/opentui-main/packages/core/src/post/`):
  - `applyScanlines()` (filters.ts) for subtle CRT effect
  - `VignetteEffect` (effects.ts) for depth
  - `applyBrightness()` / `applyGain()` (filters.ts) for theme transitions
  - `applySaturation()` (filters.ts) for color adjustment
  - `applyChromaticAberration()` (filters.ts) for chromatic aberration
  - `applyNoise()` / `applyInvert()` (filters.ts) for additional effects
  - **Colorblind simulation** via matrices from `matrices.ts` (`PROTANOPIA_SIM_MATRIX`, `DEUTERANOPIA_SIM_MATRIX`, `TRITANOPIA_SIM_MATRIX`, `ACHROMATOPSIA_MATRIX`) applied through `buffer.colorMatrix(matrix, cellMask, 1.0, 3)` — NOT a standalone function
  - **Note:** Gamma correction is NOT exposed in the OpenTUI post-processing API. Dropped from scope. If needed in future, requires adding a new matrix/filter to OpenTUI core.
- **SyntaxStyle** from Phase A for syntax highlighting
- **TextAttributes** for rich text styling

## Error Handling (Law 14)

| Failure Mode | Graceful Degradation |
|--------------|---------------------|
| Native render lib not loaded | Skip ALL post-processing silently. Log a single warning. Never crash the TUI for a cosmetic feature. |
| `applyScanlines()` throws | Catch, log, continue without scanlines. |
| `VignetteEffect` fails to initialize | Catch, log, continue without vignette. |
| `applyBrightness()`/`applyGain()` throws | Catch, log, continue with unadjusted brightness. |
| Colorblind matrix application fails | Catch, log, continue without colorblind simulation. |
| `Timeline`/`useTimeline` unavailable | Fall back to instant transitions (no animation). |
| `SyntaxStyle` from Phase A unavailable | Fall back to plain text code blocks (Phase C baseline). |

**Principle:** Every post-processing call must be wrapped in a try/catch that degrades to "no effect" rather than "crash". The TUI must remain functional even if every cosmetic feature is disabled.
